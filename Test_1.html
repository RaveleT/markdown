1. Cholesky Method (15 Marks Scope)

Core Concept & Conditions

  • Cholesky's method is a direct method used to solve a linear system $Ax = b$ specifically when $A$ is a symmetric positive definite matrix.

  • A matrix $A$ satisfies this if $A = A^T$ and all its eigenvalues are positive (or all leading principal submatrix determinants are positive: $\det(A_i) > 0$).

  • Any symmetric positive definite matrix can be factorized into:

$$A = LL^T$$

where $L$ is a lower triangular matrix with positive diagonal entries.

Step-by-Step Procedure

  1. Factorization: Set up $LL^T$ using unknown elements $l_{ij}$ of the lower triangular matrix $L$:

$$LL^T = \begin{pmatrix} l_{11} & 0 & 0 \ l_{21} & l_{22} & 0 \ l_{31} & l_{32} & l_{33} \end{pmatrix} \begin{pmatrix} l_{11} & l_{21} & l_{31} \ 0 & l_{22} & l_{32} \ 0 & 0 & l_{33} \end{pmatrix}$$

  1. Compute Entries: Multiply row by row and equate entries to matrix $A$ to solve for $l_{ij}$ sequentially.

  2. Forward Substitution: Introduce $y = L^T x$, and solve the lower-triangular system $Ly = b$ for the intermediate vector $y$.

  3. Backward Substitution: Solve the upper-triangular system $L^T x = y$ to find the final solution vector $x$.

Example from Notes

  • System: Solve $\begin{pmatrix} 1 & -3 & 4 \ -3 & 34 & -17 \ 4 & -17 & 18 \end{pmatrix} \begin{pmatrix} x_1 \ x_2 \ x_3 \end{pmatrix} = \begin{pmatrix} 9 \ 38 \ 25 \end{pmatrix}$.

  • Lower Matrix $L$:

$$L = \begin{pmatrix} 1 & 0 & 0 \ -3 & 5 & 0 \ 4 & -1 & 1 \end{pmatrix}$$

  • Intermediate Vector $y$: Solving $Ly = b$ yields $y = (9, 13, 2)^T$.

  • Final Solution $x$: Solving $L^T x = y$ yields $x = (10, 3, 2)^T$.

2. Iterative Methods: Jacobi Method (20 Marks Scope)

Overview of Iterative Techniques

  • Iterative methods start with an initial approximation $x^{(0)}$ and generate a sequence of vectors ${x^{(k)}}$ converging to the true solution $x$.

  • They are highly efficient for large, sparse systems with a high percentage of zero entries, significantly reducing storage and round-off error accumulation compared to direct methods.

Component-Form Formulation

  • Solving the $i$-th equation in $Ax = b$ for $x_i$ (provided $a_{ii} \neq 0$) yields the Jacobi component formula:

$$x_i^{(k)} = \frac{1}{a_{ii}} \left[ b_i - \sum_{\substack{j=1 \ j \neq i}}^{n} a_{ij} x_j^{(k-1)} \right], \quad \text{for } i = 1, 2, \dots, n$$

Matrix-Form Formulation

  • Matrix $A$ is split into its diagonal ($D$) and off-diagonal negative parts ($L$ and $U$), such that $A = D - L - U$.

  • The Jacobi method can be expressed in the fixed-point iteration form:

$$x^{(k)} = Tx^{(k-1)} + c$$

Convergence Theorem

  • For the iterative method to converge regardless of the starting point $x^{(0)}$, it is necessary and sufficient that the spectral radius of the iteration matrix satisfies $\rho(T) < 1$ (or equivalently, that the matrix norm $\vert{}\vert{}I - Q^{-1}A\vert{}\vert{} < 1$).

$$-x_1 + 2x_2 - x_3 = 0$$

$$-x_2 + 2x_3 = 1$$

Initial guess: $x^{(0)} = \begin{pmatrix} 0 \ 0 \ 0 \end{pmatrix}$

Exact solution: $x = \begin{pmatrix} 1 \ 1 \ 1 \end{pmatrix}$

Step 1: Find the Iteration Matrix $T_{jac}$ and Vector $c_{jac}$

Write the system in matrix form $Ax = b$:

$$A = \begin{pmatrix} 2 & -1 & 0 \ -1 & 2 & -1 \ 0 & -1 & 2 \end{pmatrix}, \quad b = \begin{pmatrix} 1 \ 0 \ 1 \end{pmatrix}$$

For the Jacobi method, split $A = D - L - U$:

  • Diagonal matrix: $D = \begin{pmatrix} 2 & 0 & 0 \ 0 & 2 & 0 \ 0 & 0 & 2 \end{pmatrix}$
  • Off-diagonal component: $L + U = \begin{pmatrix} 0 & 1 & 0 \ 1 & 0 & 1 \ 0 & 1 & 0 \end{pmatrix}$

Find $D^{-1}$:

$$D^{-1} = \begin{pmatrix} 1/2 & 0 & 0 \ 0 & 1/2 & 0 \ 0 & 0 & 1/2 \end{pmatrix}$$

Calculate $T_{jac} = D^{-1}(L + U)$ and $c_{jac} = D^{-1}b$:

$$T_{jac} = \begin{pmatrix} 1/2 & 0 & 0 \ 0 & 1/2 & 0 \ 0 & 0 & 1/2 \end{pmatrix} \begin{pmatrix} 0 & 1 & 0 \ 1 & 0 & 1 \ 0 & 1 & 0 \end{pmatrix} = \begin{pmatrix} 0 & 0.5 & 0 \ 0.5 & 0 & 0.5 \ 0 & 0.5 & 0 \end{pmatrix}$$

$$c_{jac} = \begin{pmatrix} 1/2 & 0 & 0 \ 0 & 1/2 & 0 \ 0 & 0 & 1/2 \end{pmatrix} \begin{pmatrix} 1 \ 0 \ 1 \end{pmatrix} = \begin{pmatrix} 0.5 \ 0 \ 0.5 \end{pmatrix}$$

Step 2: Show Convergence Using the Spectral Radius

Find the eigenvalues of $T_{jac}$ by solving $\det(T_{jac} - \lambda I) = 0$:

$$\det \begin{pmatrix} -\lambda & 0.5 & 0 \ 0.5 & -\lambda & 0.5 \ 0 & 0.5 & -\lambda \end{pmatrix} = 0$$

Expanding the determinant:

$$-\lambda(\lambda^2 - 0.25) - 0.5(0.5(-\lambda)) = 0$$

$$-\lambda^3 + 0.25\lambda + 0.25\lambda = 0$$

$$-\lambda^3 + 0.5\lambda = 0 \implies -\lambda(\lambda^2 - 0.5) = 0$$

The eigenvalues are:

$$\lambda_1 = 0, \quad \lambda_2 = \sqrt{0.5} \approx 0.7071, \quad \lambda_3 = -\sqrt{0.5} \approx -0.7071$$

The spectral radius $\rho(T_{jac})$ is the maximum absolute eigenvalue:

$$\rho(T_{jac}) = \max(\vert{}\lambda_i\vert{}) = \sqrt{0.5} \approx 0.7071$$

Since $\rho(T_{jac}) < 1$, the Jacobi iteration method converges for any initial guess.

Formula: $x^{(k)} = T_{jac}x^{(k-1)} + c_{jac}$

Convergence Theorem of an Iterative Solver

Theorem:
A stationary linear iterative method of the form $x^{(k)} = Tx^{(k-1)} + c$ converges to the unique solution of the system for any arbitrary initial guess $x^{(0)}$ if and only if the spectral radius of the iteration matrix $T$ is strictly less than 1:

$$\rho(T) < 1$$

where the spectral radius $\rho(T)$ is defined as the maximum absolute value of the eigenvalues of $T$:

$$\rho(T) = \max_i \vert{}\lambda_i\vert{}$$
